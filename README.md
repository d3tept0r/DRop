# DRop
DRop is a 3D-printable part designed for holding an SG90 servo.

## Overview
This repository contains the .prt and .stl files to 3D print or modify the part to your needs.

The current design is based on an SG90 servo motor mounting bracket with M3 screw points spaced 30 × 30 mm apart.

## Materials
Compatible with any filament

## Printing Instructions
1. Download the model files from this repository.
2. Open the STL or supported model file in your preferred slicer.
3. Select your printer and filament profile.
4. Set the print parameters to your taste. Use supports for strength.
5. Slice the model.
6. Print the part and check the mounting holes for fit.
